# Personnal portfolio

This is my personal portfolio as a student in computer science, built using **React** and **Vite**.

The goal of this project is to explore modern web development techniques, including smooth scrolling, custom animations, and interactive layouts, while keeping the design minimalist.

## Tech Stack

* **Core:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Animation:** [Framer Motion](https://www.framer.com/motion/)
* **Scroll Physics:** [Lenis](https://github.com/darkroomengineering/lenis)
* **Linting:** ESLint + Prettier
